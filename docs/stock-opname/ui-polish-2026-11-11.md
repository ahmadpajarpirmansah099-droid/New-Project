# Stock Opname — FAB dan penyelarasan form

## Tujuan dan keputusan user

User melaporkan lima ikon FAB identik, Sales menimpa Stock Awal, dan tampilan semua form Stock Opname belum selaras dengan fitur lain. User meminta mencari referensi ikon dan mengerjakan perbaikan. Baseline diperiksa pada `main` commit `c4008cc2daf48ea5a8f529f0f9bb6f285af2b50e`, sesudah PR #227 dan pemasangan schema.

## 1. Perilaku yang disengaja

- FAB Stock Opname menampilkan Stock Awal, Pengeluaran, Barang Masuk, Produksi WIP, lalu Sales dari atas ke bawah. Setiap aksi memakai ikon Lucide yang berbeda; label teks tetap tersedia.
- Susunan memakai aliran flex dengan jarak antarbaris, bukan posisi absolut berdasarkan nomor child HTML. Item dari konteks lain tidak mengambil tempat. Daftar dibatasi tinggi viewport dan dapat digulir pada layar pendek.
- Urutan visual lama menu Guest dan Master dipertahankan. Animasi bertahap mengikuti indeks item yang benar-benar terlihat.
- Form tetap input langsung. Stock Awal/opname HP tetap satu bahan dalam satu baris; stok sistem tampil di bawah nama. Desktop tetap lima kolom.
- Khusus Barang Masuk pada HP, nama barang mendapat lebar penuh, lalu jumlah/satuan/invoice berada pada satu deret berlabel di bawahnya. Ini mencegah kolom invoice menyempitkan nama barang.
- Tanggal Sales dapat turun ke baris berikutnya pada layar sempit. Form memakai petunjuk singkat, footer aksi, dan riwayat kosong yang lebih jelas.

## 2. Batas keamanan

- Perubahan hanya presentasi dan penempatan menu. Tidak ada perubahan database, RLS, RPC, autentikasi, penugasan akun, service transaksi, rumus, harga, resep, atau payload penyimpanan.
- Tidak menambah dependency aplikasi. SVG Lucide dipakai inline seperti pola ikon repo sebelumnya.
- Tidak mengubah/menghapus `waitlist_frontend_demo_v1` atau key draft. Tidak menulis transaksi produksi atau Stock Awal untuk pengujian tampilan.
- Escaping nama barang, label aksesibilitas, field dataset, validasi, request ID retry, dan pemulihan draft tetap dipertahankan.

## 3. Detail implementasi dan arah visual

Jenis UI: form operasional admin. Arah: tabel kerja padat dengan identitas New-Project, mengikuti Master Barang/WIP/Menu. Aksen lime untuk aksi utama, navy untuk teks, dan surface terang. Tidak ditambah hero/KPI/dekorasi baru.

Token diambil dari `visual-tokens.css`: DM Sans untuk isi, Manrope untuk judul, radius kontrol 12px/kartu 18px, shadow kontrol/kartu yang sama, serta easing `--ui-ease`. Hierarki 23–26px untuk judul halaman, 18–20px untuk judul form, 12–13px untuk label/keterangan. Input 16px dan tinggi minimal 44px. Motion hanya pembukaan form, menu, fokus, dan penekanan tombol; reduced-motion mematikan animasi form.

- Menu Guest/Master setelah pergantian halaman. Routing/visibility sudah diperiksa lewat VM; interaksi sentuh/keyboard browser belum diulang.
